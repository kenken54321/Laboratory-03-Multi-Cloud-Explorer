# Reflection — Multi-Cloud Explorer

### 1. Which cloud platform impressed you the most?

The cloud platform that impressed me the most is **Google Cloud Platform (GCP)** because of its strong capabilities in Artificial Intelligence, Machine Learning, data analytics, and Kubernetes. Services such as Vertex AI, BigQuery, and Google Kubernetes Engine provide useful tools for developing modern and scalable applications. I also found GCP's infrastructure and cloud-native technologies useful for different types of workloads.

### 2. What similarities exist among AWS, Azure, and GCP?

AWS, Azure, and GCP all provide similar core cloud services, including **virtual machines, object storage, databases, networking, and identity management**. They also support scalability, security, high availability, and pay-as-you-go cloud computing. Although the names of their services are different, they provide many equivalent solutions for hosting applications and managing business workloads.

### 3. How do business requirements influence cloud platform selection?

Business requirements help determine which cloud platform is most suitable for an organization. Factors such as **budget, existing technology, security, scalability, performance, location, and application requirements** should be considered before choosing a provider. For example, Azure is a strong choice for organizations already using Microsoft technologies, while GCP may be better suited for AI and Machine Learning workloads.

### 4. What did you learn from acting as a Cloud Solutions Consultant?

Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider is not simply about selecting the most popular platform. I learned to analyze the client's specific needs and match them with the appropriate cloud services and capabilities. I also learned that understanding services such as compute, storage, networking, identity, and Kubernetes is important when designing an effective cloud solution.
