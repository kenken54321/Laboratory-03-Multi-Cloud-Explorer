# Cloud Provider Recommendations for Each Client

## Client A — Startup

### Recommended Provider: **AWS**

AWS is a good choice for a startup because it provides a wide range of cloud services and flexible options for scaling as the application grows. The startup can begin with a small amount of resources to keep costs manageable and increase resources as the number of users increases. AWS also provides managed services that can reduce the amount of infrastructure the startup needs to maintain. Its large ecosystem gives the startup many options as the application becomes more complex.

### At least 3 Cloud Services:

1. **Amazon EC2** – Provides virtual servers for running the application's backend.
2. **Amazon S3** – Stores images, videos, files, and other application data.
3. **Amazon RDS** – Provides a managed relational database for storing user and application information.
4. **Amazon VPC** – Provides a secure virtual network for the application.
5. **AWS Lambda** – Allows the startup to run code without managing servers.

**Final Choice: AWS**

---

## Client B — University

### Recommended Provider: **Microsoft Azure**

**Microsoft Azure is the best choice for the university because it already uses Windows Server, Microsoft 365, and Active Directory.** Azure provides strong integration with Microsoft's existing technologies, which can make cloud migration easier and reduce the need to completely change the university's current environment. Microsoft Entra ID can also provide cloud-based identity and access management that works with Microsoft's ecosystem. Azure's hybrid-cloud capabilities allow the university to keep some services on-premises while gradually moving other services to the cloud.

### At least 3 Cloud Services:

1. **Azure Virtual Machines** – Can host Windows Server workloads in Azure.
2. **Microsoft Entra ID** – Provides identity and access management.
3. **Azure Virtual Network (VNet)** – Connects and secures cloud resources.
4. **Azure Blob Storage** – Stores university documents, backups, and other files.
5. **Azure SQL Database** – Provides a managed database service.

**Final Choice: Microsoft Azure**

---

## Client C — AI Research Company

### Recommended Provider: **Google Cloud Platform (GCP)**

**GCP is the best choice for the AI research company because Google has strong capabilities in artificial intelligence, machine learning, data analytics, and cloud-native computing.** Google Cloud provides specialized AI and machine-learning services that can help researchers develop, train, and deploy AI models. It also provides powerful computing resources that can be used for demanding research workloads. GCP's Kubernetes capabilities are also useful for managing scalable AI and machine-learning applications.

### At least 3 Cloud Services:

1. **Vertex AI** – Provides tools for developing, training, and deploying AI and machine-learning models.
2. **Compute Engine** – Provides scalable virtual machines for high-performance computing workloads.
3. **Google Kubernetes Engine (GKE)** – Manages containerized AI and research applications using Kubernetes.
4. **BigQuery** – Allows researchers to analyze very large datasets.
5. **Cloud Storage** – Stores datasets, models, research files, and experiment results.

**Final Choice: GCP**

---

## Client D — Global E-Commerce

### Recommended Provider: **AWS**

**AWS is a suitable choice for a global e-commerce company because it has extensive global infrastructure and a large selection of services for building highly available and scalable applications.** The company can deploy applications across multiple AWS Regions and Availability Zones to improve availability and resilience. AWS also provides services that can automatically scale computing resources when customer traffic increases. This makes AWS suitable for handling unpredictable traffic during sales, holidays, and other high-demand periods.

### At least 3 Cloud Services:

1. **Amazon EC2** – Provides computing resources for the e-commerce application.
2. **Amazon S3** – Stores product images, videos, documents, and other files.
3. **Amazon RDS** – Provides a managed database for customers, products, orders, and transactions.
4. **Elastic Load Balancing (ELB)** – Distributes incoming traffic across multiple application resources.
5. **Amazon EC2 Auto Scaling** – Automatically increases or decreases compute capacity based on demand.
6. **Amazon CloudFront** – Delivers website content to users through a global content delivery network.

**Final Choice: AWS**
